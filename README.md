# 🎬 TuneUP - Audio Equalizer & 5.1 Virtual Surround

Ekstensi Google Chrome untuk meningkatkan kualitas suara YouTube, Netflix, Spotify Web, dan tab aktif lainnya dengan **10-Band Equalizer**, **5.1 Virtual Surround Sound**, **Bass Bulat**, dan **FLAC Master Restorer**.

---

## 🚀 Panduan Instalasi di Google Chrome

Ikuti langkah mudah berikut untuk memasang ekstensi ini di browser Google Chrome Anda:

### Langkah 1: Unduh Berkas Ekstensi
1. Unduh kode repositori ini:
   - Klik tombol hijau **Code** di bagian atas halaman GitHub ini, lalu pilih **Download ZIP**.
   - *(Atau gunakan `git clone https://github.com/diptapraja/eq-chrome.git` jika terbiasa dengan Git).*
2. Ekstrak file ZIP yang telah diunduh ke folder di komputer Anda (misalnya di folder *Downloads* atau *Documents*).

---

### Langkah 2: Pasang di Google Chrome
1. Buka browser **Google Chrome**.
2. Ketik atau salin alamat berikut di bilah alamat (*address bar*) lalu tekan Enter:
   ```text
   chrome://extensions
   ```
3. Di pojok kanan atas layar, aktifkan tombol sakelar **Developer mode** (*Mode pengembang*).
4. Klik tombol **Load unpacked** (*Muat yang belum dibongkar*) yang muncul di pojok kiri atas.
5. Arahkan dan pilih **folder hasil ekstrak** Anda (pilih folder utama yang di dalamnya terdapat file `manifest.json`).
6. Ekstensi **TuneUP** telah berhasil terpasang dan siap digunakan!

---

### Langkah 3: Menjalankan Ekstensi
1. Klik ikon puzzle (🧩) di pojok kanan atas toolbar Chrome, lalu klik ikon pin (📌) di sebelah **TuneUP** agar muncul di toolbar.
2. Buka tab yang memutar suara (seperti YouTube atau Spotify).
3. Klik ikon **TuneUP** di toolbar, lalu klik tombol **Power** (tombol daya di kanan atas) untuk mengaktifkan equalizer dan efek surround 5.1.
4. Pilih preset bawaan (seperti *Cinema 5.1*, *FLAC Master HD*, *Spatial 3D*) atau atur slider suara sesuai selera Anda!
